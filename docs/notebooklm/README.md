## ⚡ Quick CLI Arsenal

### Status & Navigation
```bash
notebooklm status                    # Show current active notebook & conversation
notebooklm list                      # List all notebooks in account
notebooklm use <notebook_id>         # Switch active notebook context
```

### Asking Questions & Interacting
```bash
notebooklm ask "How do I size a trade using the CPR model?"
notebooklm suggest-prompts           # Get AI-suggested questions from the sources
```

### Source Management
```bash
notebooklm source list               # List all indexed sources
notebooklm source add <path_or_url>  # Upload a new markdown, pdf, or URL
notebooklm source delete <source_id> # Remove an outdated source
```

### Artifact Generation & Downloads
```bash
notebooklm artifact list             # View all studio artifacts
notebooklm generate audio "..."      # Generate a fresh podcast deep dive
notebooklm generate slide-deck       # Generate presentation decks
notebooklm generate report           # Generate operational playbooks
notebooklm generate infographic      # Generate visual blueprints (bento-grid, portrait)

# Downloading:
notebooklm download infographic -a <id> my_infographic.png
notebooklm download slide-deck -a <id> my_deck.pdf --format pptx
notebooklm download audio -a <id> my_podcast.m4a
```
